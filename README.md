# 🛟 Rescue Track AI

**An SOS-based disaster-relief assistance frontend prototype built for the Hackverse hackathon.**

## 🌍 About the Project

Rescue Track AI aims to simplify emergency assistance during disasters such as floods, cyclones, earthquakes, and other critical situations. It features a simple interface that allows users to access an SOS button and view their location after granting browser permission.

## ✨ Features

- 🔴 **One-Tap SOS:** A prominent red SOS button for emergency assistance.
- 📍 **Location Detection:** Retrieves geographical coordinates using the browser's Geolocation API.
- 🆔 **Demo Tracking ID:** Displays a demonstration tracking ID.
- 🗺️ **Google Maps Integration:** Opens coordinates on Google Maps.
- 🖥️ **Host Dashboard:** Displays sample emergency alerts, statuses, and tracking information.
- 📱 **Responsive Design:** Supports mobile, tablet, and desktop screens.
- 🔎 **Interactive Interface:** Includes navigation, search, and filtering features.

## 🛠️ Technologies Used

- React
- TypeScript
- HTML5
- CSS3
- Lucide React
- Browser Geolocation API

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## 📍 How It Works

1. Open the Rescue Track AI homepage.
2. Press the red SOS button.
3. Allow location access in your browser.
4. View your coordinates and demo request confirmation.
5. Open the host dashboard to explore sample emergency alerts.
